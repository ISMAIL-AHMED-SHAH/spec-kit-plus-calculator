## Usage

The calculator provides four basic operations: `add`, `subtract`, `multiply`, and `divide`.

### Addition

```bash
calculator add 10 5
```
Output:
```
15
```

### Subtraction

```bash
calculator subtract 10 5
```
Output:
```
5
```

### Multiplication

```bash
calculator multiply 10 5
```
Output:
```
50
```

### Division

```bash
calculator divide 10 5
```
Output:
```
2
```

### Division by Zero

```bash
calculator divide 10 0
```
Output:
```
Error: Division by zero is not allowed.
```
